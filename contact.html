Contact

Bug reports, tool requests, and everything else.

This site is run by one person, so replies aren't instant — but every message gets read. The fastest way to reach me is email:

What to include

For a bug report: which tool, what browser and device, and what you expected to happen instead. For a tool request: the specific, repeated task you want handled — the more concrete, the more likely it gets built.

Response time

Usually within a few days. This is a side project alongside full-time work and study, so please be patient.
